# Главная страница GitHub Сержа — https://sergeisysoev.github.io/

Начато 2026-11-19 по слову Сержа. Это единственный адрес, который он даёт людям: с главной они сами
переходят на калькулятор, мото-тест, тренажёр к тестам курса и всё, что появится позже. Сайт открытый,
его должны находить через поиск.

## Правила
- **Старые адреса не трогать.** Калькулятором по https://sergeisysoev.github.io/hvac-pro-calculator/
  уже пользуются люди. Главная только ссылается на проекты, каждый живёт в своём репозитории.
- **Свой домен к этому репозиторию не подключать** (файл CNAME): GitHub тогда переносит все проекты
  на этот домен.
- **С sergeisysoev.com не связывать** ни в одну сторону: по правилу того сайта там нет профсоюза
  и учёбы, а на GitHub лежит тренажёр к тестам курса.
- Город, работодатель, личные данные — не писать.
- Язык: EN по умолчанию, РУ переключателем (по языку браузера при первом заходе). Термины трейда
  в русском тексте — по-английски.
- Новый проект: карточка в `index.html` + строка в `sitemap.xml` + README. Недостроенное —
  карточка с пометкой «в работе», без ссылки.

## Выкладка
`git push` в main → GitHub Pages сам публикует за 1–2 минуты. Проверять живой адрес по содержимому
страницы (curl и поиск нужной строки), а не по коду 200.
